Course Calendar

github.com/breed34/FlutterCalendarV2

An app for tracking college course assignements. This is a personal project I developed for my own use.

Functionality

Allows the user to create courses, add assignments to those courses, and mark assignemnts complete. The app also includes a checklist view of the assignments and a CSV upload option for courses.

Technologies

The app was created using Flutter and is a Progressive Web App allowing users to install it to their smart phone homescreen. The project uses Google Firebase as a backend.

Goal Tracker

github.com/breed34/goal-tracker

An app for tracking daily goals. This is a personal project I developed for my own use.

Functionality

Allows the user to create goals, mark those goals as complete, view goal progress, and add accountability partners for extra motivation. The user can view each accountability partner's goals and progress as well.

Technologies

The app was created using Vue 3 and is a Progressive Web App allowing users to install it to their smart phone homescreen. The project uses Google Firebase as a backend. The project also uses the PrimeVue component library with Tailwind CSS.
